================================================================================
LOS 4 ESTADOS
================================================================================

1. NO ENVIADO
   ├─ Nunca subió nada
   └─ Acción: Contactar y recordar

2. INCOMPLETO
   ├─ Subió algo pero falta (ej: solo frente, sin reverso)
   └─ Acción: Recordar completar

3. COMPLETO
   ├─ Subió ambas fotos
   └─ Acción: En revisión

4. APROBADO ✅
   ├─ Fue revisado y aprobado
   └─ Acción: Ninguna, puede usar

LOS 7 SCRIPTS
================================================================================

SCRIPT 1: Tutores que SÍ verificaron
  → Ver quiénes completaron la verificación

SCRIPT 2: Tutores que NO verificaron
  → Ver quiénes faltan (para contactarlos)

SCRIPT 3: RESUMEN (⭐ EL MEJOR)
  → Todos los tutores con su estado
  → Ver el panorama completo

SCRIPT 4: Contar por estado
  → Estadísticas: cuántos en cada estado
  → Porcentaje de cumplimiento

SCRIPT 5: Exportar para contactar
  → Emails de tutores sin verificación
  → Copia directa para enviar recordatorios

SCRIPT 6: Detalle de 1 tutor
  → Cambia 123 por ID del tutor
  → Ver todo sobre ese tutor

SCRIPT 7: Incompletos - Qué falta
  → Qué documentos faltan por tutor
  → Contactar de forma específica
